# RFC

Request for Comments — a written proposal shared early and openly for feedback before a decision is finalized. Originates in the IETF internet-standards process; adopted by tech organizations as an inner-source practice for internal design decisions. It is "release early, release often" applied to decision-making instead of code: expose the idea to many eyes before it hardens.

---

## Connection to our work

The proposal half of the [[raymond-the-cathedral-and-the-bazaar]] model translated to organizations. Paired with an [[adr]], it closes the loop between an open proposal and the recorded reasoning behind the eventual decision — without that pairing, an RFC process has bazaar-access but no bazaar-legacy.
