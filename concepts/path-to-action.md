# Path to Action

Uit [Crucial Conversations](../books/patterson-crucial-conversations-tools-for-talking-when-stakes-are-high.md): het causale pad van waarneming naar gedrag.

```
See / Hear / Sense  →  Tell a Story  →  Feel  →  Act
```

We reageren niet op feiten — we reageren op de **verhalen** die we over feiten vertellen. Die tussenliggende stap is onzichtbaar maar bepalend. Wat we beleven als directe reactie (*Feel → Act*) is in werkelijkheid altijd gemedieerd door een verhaal.

Implicatie: wil je anders handelen, verander dan niet het gevoel maar het verhaal. Zie [[villain-stories]] voor de drie meest voorkomende disfunctionele verhalen.
